# ENGINEER IT - Game Setup
   
### Prerequisites
Download and install the LTS version of Node.js from https://nodejs.org.
   
### How to Run the Game
1. Extract this ZIP file and open the extracted folder in a terminal (or VS Code).
2. Run `npm install` to download all the necessary project files.
3. Run `node server.js` to start the game server.
4. Open a **second** terminal window in the same folder and run `npm run dev` to start the user interface.
5. Open your browser and go to the local links shown in the terminal (usually http://localhost:5173/host and http://localhost:5173/play).
